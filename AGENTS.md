## What this is

The Howling Whispers is a roleplay storytelling web app (React/Next, `app/dreambound-app.tsx`)
with four curated characters: **Coda**, **Heather Whiteclaw**, **Peony**, **Senako Steel**.
Stories are generated by NovelAI (cloud) or Ollama (local/device). The entrance rotates
featured portraits including a "Curation call" ad card linking to the owner's Discord:
`https://discord.gg/jrJRrAXBRH`.

## Deploy pipeline (LOCKED — follow exactly)

1. **Work on `dev` only.** Never touch `main`/live without the user's explicit approval.
2. In `/var/www/HowlingWhispers-dev`:
   - `git pull` (fast-forward `dev` from origin) if not up to date.
   - Make changes, run `npm test`, `npm run lint`, `npm run build`.
   - `git add` the intended files, commit with a concise message, `git push origin dev`.
3. In `/var/www/HowlingWhispers` (main checkout):
   - `git fetch origin`
   - `git merge --ff-only origin/dev`
   - `git push origin main`
4. Run `/usr/local/sbin/howlingwhispers-promote` — it builds in a fresh worktree,
   runs tests/lint, does a candidate health check, then atomically switches the symlink
   and restarts via `howlingwhispers-candidate.service`.
5. **After every deploy, restart the sandbox** or it serves a stale asset manifest
   (blank/white page): `systemctl restart thehowlingwhispers-dev.service`.
6. Verify the live release served `(e.g. curl the page and check the bundle hash)`, and
   hard-refresh to avoid stale caching. This was the cause of the earlier "white page".

## Content / formatting rules (must be enforced)

- Message/reply format: actions & observable narration in `*single asterisks*`, inner
  voice in `[square brackets]`, **spoken dialogue as plain text with NO quotation marks**,
  blank lines between beats. Strips speaker labels.
- The message renderer (`renderMessageText` ~line 2422) splits on `*…*` blocks; keep the
  format uniform.
- Character profiles sent to the model should end with a speech-style paragraph stating
  the formatting rules. `{{char}}`/`{{user}}` are NOT templated in-app — replace them with
  the character name / "you" when authoring content.

  `curl -H "Origin: https://rp.thehowlingwhispers.com" http://127.0.0.1:11434/api/tags`.
- **Local** provider: Ollama on the website server (CPU-only Netcup), model
  `R4C3R/gemma-3-12b-it-heretic:q4_k_m`, kept hot with `OLLAMA_KEEP_ALIVE=-1`.
- The connection test (settings) runs as a plain fetch; the user does NOT need to stay on
  the settings screen, but must keep the page/tab open (the panel is inline, not a modal).

## Scene art workflow

- Art assets come from ChatGPT generation and are delivered as Discord attachment links.
- Download the **original** with the signature params from
  `https://cdn.discordapp.com/attachments/...` (media.discordapp.net with `format=webp` is a
  preview; cdn gives the original PNG). Verify 16:9 (typically 1672×941) before committing.
- Save as `public/assets/Heather/heather-whiteclaw-<scene>.png`, then update the scene's
  `background` in `handcraftedScenes` and tune `backgroundFocalPoint`.
- The edit/delete story buttons are for custom scenes only (`scene.id.startsWith("custom-")`);
  curated scenes are locked.
