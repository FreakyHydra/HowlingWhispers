Relationship model

Stop collapsing relationships into one number.

A character can trust someone, fear them, love them, resent them and still feel safe around them in different amounts. RS V2 should preserve those contradictions instead of averaging them away.

Momentum + inertia

The same score can mean very different things depending on how it got there. A trust value of 68 after months of growth is not the same state as 68 after falling from 95 following a betrayal.

trust.value = 68 trust.velocity = +4.2 trust.stability = 0.71 new relationship → high volatility established relationship → high inertia major event → can break through inertia

Fear is not hostility.

If a player backs away because they are frightened, the event interpreter should not turn negative sentiment into a relationship punishment. The player signal, the character's appraisal, and the eventual relationship effect are separate stages.

PLAYER SIGNAL fear +0.72 • hostility +0.03 • vulnerability +0.61 CHARACTER APPRAISAL "They are afraid of me." POSSIBLE RELATIONSHIP EFFECT trust -1 • fear +5 • protectiveness +7 • resentment 0
Derkomor research

ObserverseQuelle becomes the embodiment layer.

Derkomor's ten-axis S10.D.D.D. architecture is most valuable when it stays focused on character behaviour and physical grounding. It can consume relationship state, memory and scene state without replacing those systems.

🧠

K / memory pressure

Old unresolved experience filters perception as predisposition rather than forcing exposition into the scene.

👁️

S / sensory grounding

Knowledge should surface through seeing, hearing, touch, pain, temperature, pressure or another concrete trigger when relevant.

🫀

V / vocal tells

Breathing, hesitation, roughness, short bursts and other vocal texture can emerge from physical and psychological pressure.

🧭

P / subjective truth

The character acts from what they believe is true, not from the omniscient truth available to the system.

🌧️

Persistent physical state

Wet clothing, dirt, tears, injury, fatigue, position and other consequences should not silently reset between turns.

🔁

Turn-level S10 state

HW can evaluate the full S10 state once per turn, then compile the useful result instead of expanding ten stages before every generated sentence.

New features

Useful systems that fall naturally out of the architecture.

These are not random extras. Each feature uses state already produced by RS V2, the embodiment layer or memory pipeline, so they can reinforce one another instead of becoming isolated prompt tricks.

🎭

Interpretation confidence

Characters do not always know what the player meant. Low confidence can produce questions, suspicion, arrogance, caution or empathy depending on personality.

🪞

Persistent misunderstandings

Keep player intent and character belief separate. A false belief remains real to the character until evidence changes it.

🧵

Causal memory

Store meaningful events together with what they caused. Retrieve by causal similarity, not only by matching words.

🗂️

Memory lanes

Separate character memory, relational memory, world memory, body state and scene memory so retrieval does not become one giant RAG soup.

⏳

Emotional aftereffects

Fear, embarrassment, grief and resentment decay at different speeds, modified by personality and circumstances.

🛡️

Continuity Guard

Before generation, detect contradictions in identity, body, relationships, scene geography and world rules, then retrieve targeted evidence only when needed.

🎲

Layered reroll

Normal reroll changes prose. Alternative reaction can reroll plausible interpretation. Divergent reroll branches from the same world state.

👥

Multi-character attention

Each cast member independently decides whether they noticed, care, react, speak or remain silent. Mentioning a character boosts relevance without forcing dialogue.

Expression Dynamics

Meter should emerge from state.

Instead of asking the model to "be varied", prose rhythm can be explicitly derived from emotion, physiology, personality, relationship pressure, voice and the current situation.

Calm

Low tempo • longer sentences • few fragments • low hesitation • deliberate action.

"I don't think that's necessary. We still have time."

Nervous

Medium tempo • shorter clauses • more pauses • qualifying questions • visible tells.

"I don't... think that's necessary. We still have time. Right?"

Panicked

High tempo • fragments • repetition pressure • short commands • action dominance.

"No. No, wait. Stop. Just stop."
Diagnostics

Make relationship changes explain themselves.

The debugging view should expose why a relationship event changed, without leaking the analysis into visible roleplay prose. This makes tuning possible when a friendly or frightened action produces a bizarre score.

Architecture rule

The LLM writes the scene. It does not own the state.

Howling Whispers owns relationships, memory, body state, world state, beliefs, event history and continuity. The provider receives the relevant state and performs the character.
