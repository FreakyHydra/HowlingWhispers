# 0.11.2.0 - RS V2: The World Remembers

This release lands the first production slice of Relationship Engine V2 and World Engine V2.

## Added

- **Relationship Engine V2 vertical slice** with multidimensional relationship state, momentum, aftereffects, causal interpretation, and persistent appraisal data.
- **World Engine V2 scene and body state persistence** across turns and backup/restore.
- **Authoritative character resolution** for Living Cast speakers, using the real card, relationships, memories, and current state before generation.
- **Regression coverage for Pip and Ragna identity resolution** and side-character participation.

## Changed

- **Relationship changes are interpreted from semantic context** rather than a simple positive or negative sentiment path.
- **Known side characters are resolved through the character registry** before they are allowed to speak.
- **Backup and restore carry RS V2 state**, including relationship dimensions, causal state, activation provenance, and World Engine state.

## Fixed

- **Prevented unresolved temporary speakers from borrowing the selected primary character's identity.**
- **Prevented a side-character name from reaching generation while another character's canon/card context was compiled.**

## Scope

This is the first production RS V2 / World Engine V2 slice. It establishes the authoritative state and identity foundation. It does not claim that every planned RS V2 interface, diagnostics surface, branching system, or deeper simulation feature is complete.
